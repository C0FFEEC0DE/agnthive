# Release Workflow

## When
Preparing for release manually.

## Status

This profile does **not** automate release or deploy.

Use this file only as a manual reminder outside the mandatory SDLC path.

## Optional Manual Checklist

### 1. Docs
Update the documentation in the root session and record the docs decision.

### 2. Review
Run `/review`: stage 1 simplifies the change and re-verifies, stage 2
dispatches the read-only Code Reviewer.

### 3. Tests
Run the suite in the root session and report the exact command and its outcome.

## Command
No automated release command in this profile.
